# ADR-0011: География — весь мир, издатель — из Беларуси

Статус: accepted (владелец, 2026-11-16) · Закрывает находку F-24
(`docs/review/01-findings.md`)

## Контекст

В спеке v0.1 география не была названа, а признаки противоречили друг другу:
RuStore и РФ-брокеры с одной стороны, Binance первой биржей — с другой. От географии
зависят выбор биржи, стора, языка и юридическая возможность платной публикации.

Владелец решил: продукт для пользователей по всему миру, издаётся из Беларуси.

## Решение

1. **Целевая аудитория — глобальная.** Язык интерфейса и документации по умолчанию —
   английский; русский — второй.
2. **Первая биржа — глобальная крипто-биржа со спотом**, как и планировалось
   (Binance). Брокеры и региональные площадки — M7.
3. **Издатель — юрлицо или физлицо из Беларуси.** Какое именно — решается до M6.
4. **Приоритет сторов для mobile:** Google Play — первым, App Store — после
   проверки, RuStore — дополнительный канал, не основной.
5. **Клин и v1 до M5 распространяются без сторов:** GitHub Releases и Telegram.
   Поэтому вопросы ниже не блокируют M0–M3.

## Последствия

- Критерий закрытия «целевой пользователь не может получить API-ключ» теперь
  относится к мировой аудитории и почти наверняка не сработает. Остаётся отдельный
  риск: владелец не может провести собственный live-тест из РБ — тогда M3 требует
  другой биржи или доверенного тестировщика.
- App Store для издателя из РБ — риск с двух сторон: правила для финансовых
  приложений и возможные блокировки аккаунтов. Mobile остаётся условным и
  последним; пульт до него — Telegram.
- Глобальная аудитория означает обработку данных пользователей из разных
  юрисдикций, как только появляются аккаунты (режим B в ADR-0009). В режиме A и без
  хостинга мы персональных данных не получаем.
- Английский по умолчанию меняет порядок локализации: `en` первым, `ru` вторым.

## Альтернативы

- **Только РФ и РБ.** Отклонено владельцем: меньше рынок, другие биржи и брокеры.
- **Издатель в другой юрисдикции.** Не рассматривалось владельцем; остаётся
  запасным вариантом, если сторы или платежи из РБ окажутся недоступны.
