# ADR-0003: Детерминированное ядро, совещательный ИИ

Статус: accepted · Дата: 2026-11-16

## Контекст

ИИ-агенты (LLM и decision-модели) полезны для анализа, но недетерминированы,
подвержены prompt injection, ошибаются и стоят денег. Прямой доступ модели к
биpже — недопустимый риск.

## Решение

Три разнесённые сущности:

- `Strategy` — детерминированный генератор сигналов;
- `Agent` — ИИ-роль, возвращающая типизированный `Proposal` (без side-effect);
- `Policy`/`RiskGate` — детерминированный слой, который решает, будет ли действие.

Путь к бирже только один: `Proposal → RiskGate → Reservation → OMS → Venue`.
У агента нет инструмента `place_order`; его права ограничены чтением и
вычислениями. Любой proposal обязан содержать `rationale`, `evidence`, TTL и
`invalidation`.

## Последствия

- Решение объяснимо: структура (signals + clamps + marks + hashes), а не текст.
- Модель можно заменить, не меняя исполнение; исполнение можно тестировать без
  модели.
- Выходы (стопы, close) не зависят от доступности ИИ.
- Появляется измеряемое качество: калибровка, стоимость, hit-rate по горизонту.
- Больше кода: нужен рантайм агентов, бюджеты, схемы, evals.

## Альтернативы

- **Автономный агент с tools на биржу**: быстрее собрать, но небезопасно и
  необъяснимо; отклонено.
- **Только детерминированные стратегии**: безопасно, но теряется продуктовая
  идея; отклонено как единственный режим.
- **LLM как сайзер**: sizing должен быть в политике; отклонено.
