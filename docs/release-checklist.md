# Чек-лист выпуска `0.1.0-m1` (предрелиз)

Выполняет **только владелец**. Агент не делает `git push`, не ставит тег, не
создаёт релиз, не запускает workflow/CI и ничего не загружает. Сборка локальная,
бесплатная: никаких платных runners, минут CI или хранилища.

Текущее состояние: релиз-кандидат `0.1.0-m1` **не опубликован**. Пока шаги ниже
не выполнены, ссылки на скачивание в `docs/install.md` не работают.

## 0. Предусловия

- [ ] Ревью RC завершено; замечания по коду и документации закрыты или явно
      отложены.
- [ ] Ветка `feat/m0-wedge-core` (или её итог) влита в `main`; рабочее дерево
      чистое.
- [ ] Локально зелёное `task check` (gen:check + lint:imports + test + build).
      Утилита `task` может быть не установлена; те же проверки обычными
      командами из корня репозитория:

  ```bash
  go -C core test ./contracts -run TestGeneratedContractsMatch   # gen:check
  go run ./tools/lintimports                                     # lint:imports
  go -C core test ./...
  go -C providers/decision-drex test ./...
  go -C providers/marketdata-binance test ./...
  go -C providers/notify-telegram test ./...
  go -C tools test ./...
  VEND_E2E=1 go -C tools test -count=1 ./e2e/...                 # сквозной тест HTTP+CLI
  python -m unittest discover -s examples/clients/python -p "test_*.py"  # test:clients:python
  go build all                                                   # build
  ```

  Сквозной тест собирает `vend` и `tools/smokestub` во временный каталог,
  поднимает оба процесса на свободных портах `127.0.0.1`, проходит сценарий
  гейта, конфликта, ошибок провайдера, разметки, перезапуска и отчёта и
  останавливает процессы по PID. Без `VEND_E2E=1` пакет `tools/e2e`
  пропускается, поэтому обычный `go test ./...` остаётся быстрым. Полный
  прогон занимает около 3 минут. PowerShell:
  `$env:VEND_E2E='1'; go -C tools test -count=1 ./e2e/...`.

  Если `python` в PATH нет, но есть `python3`, используйте
  `python3 -m unittest discover -s examples/clients/python -p "test_*.py"`:
  задача `test:clients:python` сама выбирает доступную команду. Если нет ни
  `python`, ни `python3`, клиентские тесты выполнить нельзя — установите
  Python 3 и повторите; молча пропускать этот шаг не нужно.
- [ ] `go run ./tools/release` ещё не запускался на грязном дереве.
- [ ] Владелец подтвердил дату публикации: она станет датой старта G1.

## 3. Локальная сборка артефактов

Из корня репозитория:

```bash
go run ./tools/release
```

- [ ] В `dist/` появились пять бинарников, тексты лицензии и манифест сумм:

  ```text
  vend_windows_amd64.exe
  vend_linux_amd64
  vend_linux_arm64
  vend_darwin_amd64
  vend_darwin_arm64
  LICENSE
  NOTICE
  SHA256SUMS
  ```

  `LICENSE` и `NOTICE` обязательны: Apache-2.0 требует передавать оба файла
  вместе с бинарниками (ADR-0012).

- [ ] `dist/SHA256SUMS` содержит по строке на каждый файл в формате
      `<sha256>  <filename>`.
- [ ] Суммы сходятся локально:

  ```bash
  cd dist && sha256sum -c SHA256SUMS
  ```

  Windows PowerShell:

  ```powershell
  Get-Content .\dist\SHA256SUMS
  (Get-FileHash .\dist\vend_windows_amd64.exe -Algorithm SHA256).Hash.ToLower()
  ```

- [ ] Бинарник запускается и печатает версию:

  ```bash
  ./dist/vend_linux_amd64 version   # vend 0.1.0-m1
  ```

- [ ] После проверки суммы **не пересобирать** артефакты: иначе манифест
      перестанет соответствовать файлам.

## 4. Перед публикацией: оценка сигналов на реальных свечах

- [ ] Владелец запускает оценку объёма `signals.trend` на реальных свечах с
      ключом decision-провайдера и настройками будущей недели:

  ```bash
  vend signals estimate --days 7
  ```

  Команда ничего не пишет в журнал, не вызывает decision-провайдера и Telegram
  и не требует секретов. Строки `SYMBOL error=...` и `verdict: low` означают,
  что до старта G1 нужно поправить `signals.trend.symbols`/`timeframe` или
  подключить свой источник сигналов через `POST /v1/gate`; см.
  [run-7-days.md](run-7-days.md), раздел «Ориентир по объёму».
- [ ] Фактический вывод сохранить вместе с датой: он входит в стартовый отчёт
      G1. Синтетические свечи `tools/smokestub` для этого шага не подходят.
