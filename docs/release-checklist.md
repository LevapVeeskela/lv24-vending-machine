# Чек-лист выпуска `0.1.0-m1` (предрелиз)

Выполняет **только владелец**. Агент не делает `git push`, не ставит тег, не
создаёт релиз, не запускает workflow/CI и ничего не загружает. Сборка локальная,
бесплатная: никаких платных runners, минут CI или хранилища.

Текущее состояние: релиз-кандидат `0.1.0-m1` **не опубликован**. Пока шаги ниже
не выполнены, ссылки на скачивание в `docs/install.md` не работают.

      отложены.
- [ ] Ветка `feat/m0-wedge-core` (или её итог) влита в `main`; рабочее дерево
      чистое.

- [ ] Владелец подтвердил дату публикации: она станет датой старта G1.

## 2. Тег

- [ ] Поставить аннотированный тег на коммит релиза:

  ```bash
  git tag -a v<version> -m "lv24-vending <version> (RC)"
  git show v<version> --stat
  ```

  Для этого RC `<version>` = `0.1.0-m1`.
- [ ] Тег не двигать и не переиспользовать: артефакты и `SHA256SUMS` должны
      соответствовать именно этому коммиту.
- [ ] Push тега — решение владельца; агент этого не делает.

## 3. Локальная сборка артефактов

Из корня репозитория:

```bash
go run ./tools/release
```

- [ ] В `dist/` появились пять файлов:

  ```text
  vend_windows_amd64.exe
  vend_linux_amd64
  vend_linux_arm64
  vend_darwin_amd64
  vend_darwin_arm64
  SHA256SUMS
  ```

- [ ] `dist/SHA256SUMS` содержит по строке на каждый файл в формате
      `<sha256>  <filename>`.
- [ ] Суммы сходятся локально:

  ```bash
  cd dist && sha256sum -c SHA256SUMS
  ```

  Windows PowerShell:

  ```powershell
  Get-Content .\dist\SHA256SUMS
  (Get-FileHash .\dist\vend_windows_amd64.exe -Algorithm SHA256).Hash.ToLower()
  ```

- [ ] Бинарник запускается и печатает версию:

  ```bash
  ./dist/vend_linux_amd64 version   # vend 0.1.0-m1
  ```

- [ ] После проверки суммы **не пересобирать** артефакты: иначе манифест
      перестанет соответствовать файлам.
